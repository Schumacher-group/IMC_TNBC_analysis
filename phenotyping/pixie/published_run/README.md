# Published Pixie run: prefix `clean`

Pixel- and cell-clustering artefacts used to produce the cell-type labels
reported in:

> *Identifying tissue states by spatial protein patterns related to
> chemotherapy response in triple-negative breast cancer.* bioRxiv (2025).
> DOI: 10.1101/2025.10.06.680783

## Provenance

- Generated by `phenotyping/pixie/2_Pixie_Cluster_Pixels.ipynb` and
  `3_Pixie_Cluster_Cells.ipynb` with `pixel_cluster_prefix = "clean"` and
  `cell_cluster_prefix = "clean"`.
- Run date: 2024-12-10 (mtime of `clean_cell_output_dir/cell_meta_cluster_mapping.csv`).
- SOM topology: 400 meta-clusters.

## How to use these artefacts

The two files that matter most are:

- `clean_pixel_output_dir/pixel_meta_cluster_mapping.csv`
- `clean_cell_output_dir/cell_meta_cluster_mapping.csv`

These contain the manual numeric-cluster → cell-type-label assignments that
the SOM does not produce on its own. The `*_channel_avg_*.csv` files describe
what marker pattern each cluster represents (useful for sanity-checking
labels). The committed `*_som_weights.feather` files let the notebooks
resume from the trained SOMs without retraining.

In both Pixie notebooks, set:

```python
base_dir              = "<path-to-this-repo>/phenotyping/pixie/published_run"
pixel_cluster_prefix  = "clean"
cell_cluster_prefix   = "clean"
…and skip the SOM-training cells.

Not included
The post-Pixie labelled cell table itself (~1 GB) is not deposited here. To
reconstruct it, run 3_Pixie_Cluster_Cells.ipynb end-to-end against the IMC
images from BioStudies S-BIAD2027 plus the artefacts in this folder.

Per-cell and per-pixel bookkeeping feathers (cluster_counts*.feather,
weighted_cell_channel.feather) were excluded because they are large and
fully regenerable from the inputs above.
