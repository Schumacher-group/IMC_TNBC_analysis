# Published Pixie run: prefix `clean`

Pixel- and cell-clustering artefacts used to produce the cell-type labels
reported in:

> *Identifying tissue states by spatial protein patterns related to
> chemotherapy response in triple-negative breast cancer.* bioRxiv (2025).
> DOI: [10.1101/2025.10.06.680783](https://www.biorxiv.org/content/10.1101/2025.10.06.680783)

## Provenance

- Generated by `phenotyping/pixie/2_Pixie_Cluster_Pixels.ipynb` and
  `3_Pixie_Cluster_Cells.ipynb` with `pixel_cluster_prefix = "clean"` and
  `cell_cluster_prefix = "clean"`.
- Run date: 2024-12-10 (mtime of `cell_meta_cluster_mapping.csv`).
- SOM topology: 400 meta-clusters.

The nested `pixie/` directory mirrors the original on-disk layout that the
Pixie notebooks expect — `base_dir/pixie/<prefix>_*_output_dir/`.

## How to use these artefacts

Both Pixie notebooks default to `base_dir = "published_run"`, which resolves
the `pixie/` subdirectory above transparently.

The two files that matter most are the `*_meta_cluster_mapping.csv`s: they
contain the manual numeric-cluster → cell-type-label assignments that the SOM
does not produce on its own. The `*_channel_avg_*.csv` files describe what
marker pattern each cluster represents (useful for sanity-checking labels).
The committed `*_som_weights.feather` files let `train_pixel_som` /
`train_cell_som` resume without retraining when present.

## Not included

The post-Pixie labelled cell table itself (~1 GB) is not deposited here. To
reconstruct it, run `3_Pixie_Cluster_Cells.ipynb` end-to-end against the IMC
images from BioStudies S-BIAD2027 plus the artefacts in this folder.

The per-cell and per-pixel bookkeeping feathers
(`cluster_counts*.feather`, `weighted_cell_channel.feather`,
`pixel_mat_data/`, `pixel_mat_subset/`) were excluded because they are large
(several GB) and fully regenerable from the inputs above.
